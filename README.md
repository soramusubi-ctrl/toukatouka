# いろぬき

背景色で選ぶ、ブラウザ内完結の透過PNGメーカー。一色に近い背景のイラスト向け。

## 使い方

1. 画像を選択・ドロップ、または添付の妖精サンプルで試す。
2. 外側につながる背景色を自動除去。必要に応じて背景色・色の範囲・輪郭を調整。
3. 囲まれた背景は「ここも抜く」で追加指定。「戻す筆」で原画を復元・保護、「消す筆」で任意の場所を除去。
4. 白・濃色・ピンクの背景でも確認し、元の画素サイズの透過PNGで保存。

画像処理と編集履歴はメモリ内。アップロード、外部API、画像生成、AI人物判定は使わない。履歴は画像サイズに応じて最大14回。最大20メガピクセル・50MB。編集内容はページを閉じると消えるため、PNGを保存する。

## 構成

- `index.html`, `style.css`, `app.mjs`: UI・入力・編集・PNG保存
- `worker.mjs`: UIを止めない処理用Worker
- `engine.mjs`: 外周の代表色・連結領域・輪郭調整・復元/消去マスク
- `sample.webp`: ユーザー提供サンプル

リポジトリ名: `toukatouka`。

静的配信のみ。ビルド・APIキー不要。HTMLと同じ場所にCSS・JS・サンプル画像を置いて、HTTP/HTTPSで配信してください（ファイルを直接ダブルクリックするとWorkerが動かない場合があります）。`node tests/engine.mjs` で領域判定とマスクの回帰検証。

## 確認済み

添付画像の暗色背景での目視確認と代表画素の確認（葉、トマト、顔、白い服、靴、羽）。合成画像で外周除去・囲まれた白の保持・背景追加・復元/消去・既存透過を検証。JS構文チェック済み。利用できるブラウザ操作環境がなく、ブラウザでの操作と端末へのダウンロードは未確認。

## 制約

背景と絵の色が同じでつながっている箇所は色だけでは区別できないため、範囲を狭めるか戻す筆で保護する。複雑な風景の人物切り抜きには非対応。出力PNGの画素サイズは保持するが、元のメタデータ・カラープロファイルの保持は保証しない。
